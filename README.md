# 🍊 CapyLib.NoRules

> **Официальный серверный геймплейный плагин для игрового режима NoRules проекта Капибара (SCP: Secret Laboratory EXILED)**

---

## 📖 О плагине

`CapyLib.NoRules` — это комплексный геймплейный плагин для серверов **NoRules**, работающий на базе фреймворка [CapyLib](https://github.com/CapybaraPR/CapyLib). Плагин объединил 8 ключевых механик, создающих динамичный, весёлый и комфортный игровой процесс с чистым экранным HUD вместо перекрывающих экран бродкастов.

Все компоненты компилируются в оптимизированную сборку **`CapyLib.NoRules.dll`** под `.NET Framework 4.8`.

## 🎮 8 Игровых подсистем

### 1. 💀 `.kill` и 🔄 `.res` (`DotResKill`)
* **`.kill`:** Живой игрок может совершить суицид с забавной причиной смерти (с кулдауном 10 сек).
* **`.res`:** Наблюдатели (Spectator) в первые 180 секунд раунда могут возродиться за Класс D (75%) или Учёного (25%). При смерти игроку выводится подсказка в верхний HUD.

### 2. ⚔️ Friendly Fire в конце раунда (`FriendlyFire`)
* При завершении раунда автоматически включается `Friendly Fire` и всем игрокам через верхний HUD отправляется оповещение:
  `<color=#f87171><b>РЕЖИМ FRIENDLY FIRE ВКЛЮЧЕН!</b></color>\n<color=#c2c2c2>Да будет резня!</color>`.
* При старте следующего раунда Friendly Fire автоматически отключается.

### 3. 🎯 Хитмаркеры и отображение урона (`Hitmarkers`)
* При нанесении урона стрелку выводится аккуратный хитмаркер в нижней зоне экрана (`-35 HP` или `💀 УБИТ!`).

### 4. ♾️ Бесконечные ресурсы (`InfinityStuff`)
* **Бесконечная рация:** Батарея рации никогда не садится (`Drain = 0`).
* **Бесконечный боезапас:** При перезарядке оружие автоматически пополняется патронами.
* **Чистый сервер:** Выброшенные на пол коробки патронов автоматически удаляются для снижения лагов.

### 5. 📻 Живой мониторинг Интеркома (`IntercomList`)
* На мониторе Интеркома в комплексе в реальном времени отображается статус (Готов / Используется / Кулдаун), кто говорит и живой счётчик оставшихся в живых:
  * Класс D, Учёные, Охрана, МОГ, Хаос, SCP и Наблюдатели.

### 6. 🍬 Розовая конфета (`PinkCandy`)
* Настраиваемый шанс (по умолчанию 35%) получить легендарную взрывную конфету `CandyKindID.Pink` из вазочки SCP-330.

### 7. 🪙 Магическая монетка (`BetterCoins`)
* При подбрасывании монетки запускается 3-секундный таймер в HUD: `Телепортация.`, `Телепортация..`, `Телепортация...`.
* С шансом 75% игрок мгновенно телепортируется в случайную комнату комплекса!

### 8. 🏃 Расширенный побег (`BetterEscape`)
* Гибкие сценарии побега:
  * Класс D без наручников ➔ Хаос / В наручниках ➔ Рядовой МОГ
  * Учёный без наручников ➔ Специалист МОГ / В наручниках ➔ Хаос
  * Охрана без наручников ➔ Сержант МОГ / В наручниках ➔ Хаос

## 📦 Сборка и деплой

```bash
dotnet build CapyLib.NoRules.csproj -c Release
```
Готовый бинарник: `bin/Release/net48/CapyLib.NoRules.dll`.
Копируется в директорию плагинов сервера EXILED:
`/root/.config/EXILED/Plugins/7777/CapyLib.NoRules.dll`
