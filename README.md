# 🍊 CapyLib.NoRules

> **Официальный серверный геймплейный плагин для игрового режима NoRules проекта Капибара (SCP: Secret Laboratory EXILED)**

---

## 📖 О плагине

`CapyLib.NoRules` — это специализированный плагин для сервера **NoRules (Port 7777)**, работающий на базе фреймворка [CapyLib](https://github.com/CapybaraPR/CapyLib). Плагин реализует динамичные игровые механики, улучшающие темп и комфорт игры без душных ограничений.

Все компоненты компилируются в легковесную сборку **`CapyLib.NoRules.dll`** под `.NET Framework 4.8`.

---

## 📁 Структура проекта

```
CapyLib.NoRules/
├── Config/               # Конфигурация плагина и всех подсистем (YAML)
│   └── NoRulesConfig.cs  # Главный конфиг: AutoDoors, FastDisarm, Hitmarkers, Broadcasts
├── EventHandlers/        # Маршрутизаторы событий EXILED

│   └── ServerEvents.cs   # События раундов и карты
├── Features/             # Игровые модули и механики
│   ├── AutoDoorsFeature.cs     # Автоматическое закрытие дверей с задержкой
│   ├── BroadcastsFeature.cs    # Приветствия, бродкасты старта и итогов раунда
│   ├── FastDisarmFeature.cs    # Ускоренное / мгновенное связывание игроков
│   └── HitmarkerFeature.cs     # Всплывающий урон и хитмаркеры при стрельбе
├── CustomItems/          # Кастомные предметы режима NoRules (на базе CapyLib)
├── CustomRoles/          # Кастомные роли режима NoRules (на базе CapyLib)
├── NoRulesPlugin.cs      # Точка входа плагина Exiled
└── README.md
```

## ⚙️ Возможности и механики

### 1. 🚪 Автоматическое закрытие дверей (`AutoDoors`)
* Автоматически закрывает открытые игроком двери через настраиваемый интервал (по умолчанию `3.5 сек`).
* Корректно игнорирует ворота Gate A/B, чекпоинты, лифты и запертые двери.

### 2. 🎯 Хитмаркеры и отображение урона (`Hitmarkers`)
* При нанесении урона стрелку отображается аккуратная подсказка с количеством снятого HP и оставшимся здоровьем цели (`-35 HP (65 HP)` или `УБИТ 💀`).

### 3. 🔗 Улучшенное связывание (`FastDisarm`)
* Опция мгновенного связывания или связывания на бегу.

### 4. 📢 Серверные оповещения (`Broadcasts`)
* Приветствие нового игрока с плейсхолдерами `%player_name%` и `%server_tps%`.
* Бродкаст о старте раунда.
* Информационная сводка в конце раунда (победившая сторона, длительность).

### 5. 🔒 Порт-биндинг (`TargetPorts`)
* Плагин активируется только на указанных в конфиге портах (по умолчанию `[7777]`), предотвращая случайную активацию на серверах других режимов (MediumRP).

## 📦 Сборка плагина

```bash
dotnet build CapyLib.NoRules.csproj -c Release
```
Готовая сборка: `bin/Release/net48/CapyLib.NoRules.dll`.
Копируется в директорию плагинов сервера EXILED:
`~/.config/EXILED/Plugins/7777/CapyLib.NoRules.dll`
