# 🍊 CapyLib.NoRules

> **Официальный серверный геймплейный плагин для игрового режима NoRules проекта Капибара (SCP: Secret Laboratory EXILED)**

---

## 📖 О плагине

`CapyLib.NoRules` — это легковесный специализированный плагин для сервера **NoRules**, работающий на базе фреймворка [CapyLib](https://github.com/CapybaraPR/CapyLib). 

Плагин полностью ориентирован на чистый экранный **HUD** без использования устаревших бродкастов (`Map.Broadcast`), а также предоставляет улучшенную динамику стрельбы и хитмаркеров.

---

## 📁 Структура проекта

```
CapyLib.NoRules/
├── Config/
│   └── NoRulesConfig.cs        # Конфигурация хитмаркеров и экранных HUD-оповещений
├── EventHandlers/
│   ├── PlayerEvents.cs         # Обработка попаданий (Hurting) и входа игроков (Verified)
│   └── ServerEvents.cs         # Обработка старта и завершения раунда
├── Features/
│   ├── HitmarkerFeature.cs     # Всплывающий урон и хитмаркеры при стрельбе (-35 HP / УБИТ 💀)
│   └── AnnouncementsFeature.cs # Экранные HUD-оповещения (замена vanilla Broadcast)
├── CustomItems/                # Кастомные предметы режима NoRules
├── CustomRoles/                # Кастомные роли режима NoRules
├── NoRulesPlugin.cs            # Точка входа плагина Exiled
└── README.md
```

## 🎮 Возможности и механики

### 1. 🎯 Хитмаркеры и всплывающий урон (`Hitmarkers`)
* При нанесении урона стрелку выводится аккуратный хитмаркер в зоне `BottomCenter`:
  * Попадание: `<color=#ff4444><b>-35 HP</b></color>`
  * Убийство: `<color=#ff0000><b>💀 УБИТ!</b></color>`

### 2. 📢 Чистые HUD-оповещения (`Announcements`)
* **Никаких перекрывающих экран бродкастов:** Все системные сообщения, приветствие при входе и итоги раунда выводятся через структурированные зоны HUD `ShowHintExtensions.ShowAnnouncement()`.

### 3. 🖼️ Зонированный экранный HUD (`CapyLib Multi-Zone`)
Система поддерживает разделение экрана на независимые зоны:
* `UpperLeft`: Чат и системные сообщения
* `UpperRight`: Список отряда и статус рации
* `LowerLeft`: Кулдауны активных способностей и предметов с прогресс-барами
* `LowerCenter`: Карточка предмета в руках (название, описание, привязки клавиш)
* `BottomCenter`: Всплывающие уведомления о подборе/выбросе предметов и хитмаркеры
* `Notification`: Центральные серверные события
